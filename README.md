# 🇮🇳 India Independence Day 2026

A beautiful interactive website created to celebrate **India's 80th Independence Day** 🇮🇳

This project is a small tribute to the spirit of freedom, unity, patriotism, and the dreams of a billion Indians.

## ✨ Features

- 🇮🇳 Animated Indian flag
- 🎆 Interactive fireworks
- ⏳ Independence Day countdown
- 🎵 Independence Day background music
- 🟠⚪🟢 Tricolour animations and effects
- 💌 Personalized Independence Day greeting
- 📱 Responsive design
- ✨ Animated particles and visual effects
- 🌐 Hosted using GitHub Pages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
